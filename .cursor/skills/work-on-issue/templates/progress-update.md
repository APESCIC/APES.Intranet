# Progress update template

Post at each meaningful point only: the plan changed, the PR opened, CI failed (and what you're doing), CI fixed, blocked, or ready for review. Not on every commit.

```markdown
**Progress update**

- Done so far: <what is finished>
- Next: <what happens next>
- Blockers: none / <what's needed from Bambie>
- Links: <PR link>, <CI run link>
```
