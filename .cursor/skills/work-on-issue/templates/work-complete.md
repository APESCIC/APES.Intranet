# Work complete template

Post when the issue's PR has merged into the version branch and its checks pass, then close the issue with `gh issue close <n> --reason completed`.

```markdown
**Work complete**

- What changed: <plain-English summary>
- How it was checked: <commands or tests, and their results>
- PR: <link> (merged into `<version branch>`)
- Anything you need to know or do: nothing / <what>
```
