# Code of conduct

APES Intranet is run by APES CIC. We want discussions, issues and pull
requests to be friendly, safe and useful for everyone.

## Our standards

- Be kind, patient and respectful. Disagree with ideas, not people.
- Use plain language and help newcomers.
- No harassment, discrimination, personal attacks, spam or advertising.

## Privacy

- Never post personal data: names, emails, phone numbers, addresses, or
  staff, volunteer, student, HR or agreement details.
- Maintainers will hide or delete posts containing personal data straight
  away.

## Security

- Never report security problems in public. Follow [SECURITY.md](SECURITY.md)
  and use a private advisory:
  <https://github.com/APESCIC/APES.Intranet/security/advisories/new>

## Enforcement

Maintainers (`apescic-director`) may edit, hide, lock, move or delete
content, and may block people who break this code. Report concerns privately
via the contact details on <https://github.com/APESCIC> or the APES CIC
website.

Adapted from the Contributor Covenant, version 2.1
(<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>).
